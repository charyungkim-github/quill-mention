# Quill-Mention 커스텀 프로젝트 규칙

## 기술 스택

- React + TypeScript + Bun

## 프로젝트 배경

공식 quill-mention (v6.1.1)을 fork하여 한글 입력 문제를 해결하는 커스텀 버전 개발

## 해결해야 할 문제

### 현재 문제점

한글 실시간 검색이 불가능합니다. 한글은 자음과 모음이 조합되는 특성상 `compositionend` 이벤트가 의도한 타이밍에 발생하지 않습니다.

### 목표

"@가"만 입력해도 즉시 "가"로 시작하는 멘션 리스트가 표시되어야 합니다. 동시에 기존 quill-mention의 모든 기능은 정상 작동을 유지해야 합니다.

## 개발 규칙

### 빌드 관련

- `npm run build` 명령을 실행하지 마세요
- 이미 `bun run build --watch`가 실행 중입니다

### 코드 수정 시 overall 규칙

**원칙**: 문제를 해결하기 위해 코드를 수정 한 후, 문제가 해결되었을지 다시한번 검토한다.

### 코드 수정 시 주석 규칙

새로운 변수나 함수를 추가할 때:

```typescript
// Rfice :: 한글 실시간 검색을 위한 composition 상태 추적
const isComposing = useRef(false)
```

- 모든 커스텀 코드에 `// Rfice ::` prefix를 붙여주세요
- fork 이후 수정 사항을 명확히 구분하기 위함입니다

### 코드 정리(Clean-up) 규칙

**원칙**: 문제 해결 과정에서 불필요한 코드는 즉시 제거합니다.

**시나리오 예시**:

1. A 방법으로 수정 → 문제 해결 실패
2. B 방법 시도 필요 → **A 코드를 모두 제거한 후** B 방법 구현
3. 단, B 방법에서 A의 일부 코드가 실제로 필요한 경우는 예외

**목적**: 실제로 필요한 수정사항만 코드베이스에 남기기 위함

## 요약

- fork한 공식 라이브러리의 한글 입력 문제 해결
- 모든 커스텀 코드는 `// Rfice ::` 주석으로 표시
- 실패한 시도는 깔끔하게 제거하고 새로운 접근 시작
- 기존 기능은 반드시 유지
